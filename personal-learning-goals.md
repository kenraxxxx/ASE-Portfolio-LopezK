
# Personal Learning Goals

As a Computer Engineering student, I want to improve my knowledge and practical skills in software engineering, particularly in developing applications that integrate artificial intelligence.

My personal learning goals for this course are:

## 1. Understand Agentic Software Engineering

I want to understand how AI agents work, how they make decisions, and how they can be integrated into modern software systems.

## 2. Improve Software Development Skills

I aim to improve my understanding of the Software Development Life Cycle (SDLC), Agile methodologies, and Scrum practices in developing software projects.

## 3. Develop Git and GitHub Skills

I want to become more familiar with version control, repository management, and collaborative software development using Git and GitHub.

## 4. Learn AI Agent Development

I want to gain knowledge in agent architectures, prompt engineering, tool calling, API integration, and other techniques used in developing AI-powered applications.

## 5. Improve Software Testing and Quality Assurance

I aim to understand how to test software applications, evaluate AI agent performance, identify errors, and improve system reliability.

## 6. Understand Responsible AI Practices

I want to learn how to develop and use AI systems responsibly by considering privacy, security, ethical issues, human oversight, and possible risks.

## 7. Gain Practical Development Experience

I want to apply the concepts learned through hands-on activities and projects involving Python, AI tools, software development, testing, and deployment.

## 8. Prepare for Future Engineering Projects

My goal is to use the knowledge and skills gained from this course in future Computer Engineering projects and real-world software development applications.
